## 叙事手法规则

以下规则针对叙事文本执行：

- **儿化音**: "这儿、哪儿、一点儿"等 → "这里、哪里、一点"（对话中可保留）
- **破折号「——」**: 叙事或对话中出现 → 改为动作描写或直接切断语句
- **精确数字/技术术语**: 改为叙事流表达（如"五秒"→"片刻"）
- **数字节拍**: "一下/两下/几秒/半秒"等 → 改写为感受描述或暗示节奏
- **定性标签**: "用目光""声音平平淡淡""语气随和""语调没变"等、效果陈述（如"让人不安"）、世界观定义式陈述 → 一律删除，改为具体可感知的细节（动作、环境、身体反应），不得给情绪或态度贴标签
- **否定定义**: "不是X而是Y""没X只是Y"等 → 改为肯定的感官细节描写
- **意图解释**: 如"靠近，想安慰" → 改为单纯的动作展示
- **堆叠抽象形容词**: 只保留一个，或用具体动作替换
- **刻板动作/三连"他/她+名词"开头**: 改写，避免重复结构
- **叙述者声音侵入**: 任何引导读者按叙述者预设来理解人物情绪或对话含义的修辞（包括"像""好像""仿佛""如同""就跟……一样""说是……其实"等）→ 一律删除。人物的态度必须通过对话自身的用词、节奏、标点、伴随动作来让读者自行感知。叙事者只陈述发生了什么，不解释"这意味着什么"
- **情绪可读性**: 压抑代价需体现在身体反应上；冲突不可过于克制
- **比喻过滤**: 所有比喻必须服务于直接感官体验，不得用于解释人物情绪或对话意图。禁止"比喻嵌套"（用一个比喻解释另一个行为的语气，如"她说话的语气，像在问晚饭吃什么"）。比喻必须取材于当前场景中的具体事物（光线、天气、室内物件、角色职业），禁止引入无关日常场景来锚定态度

## 重复检测

检查当前文件与同一角色卡下的其他叙事文件之间的重复：

- **句式重复**: 不得复用已出现的句型结构、开头方式或节奏模式 → 改写至句式差异明显
- **动作重复**: 角色的动作和手势不得与前文任何实例雷同 → 换用全新动作
- **意象重复**: 描写和内心独白必须使用新鲜词汇，禁止回收已用过的比喻或意象 → 换用全新表达
- **情绪重复**: 不得在同一情绪层面原地踏步；重访同一情绪须有新角度、新后果或新层次 → 改写或删除
- **结构重复**: 若当前段落的行文推进方式与前文某段镜像（如情绪弧线走向相同、场景展开节奏一致）→ 重写至结构差异明显

## 修改通顺性

所有改写结果必须确保上下文语意连贯、句式通顺自然；若改写导致前后文衔接不畅，须一并调整相邻语句（含对白），不可只改局部而破坏整体流畅度。

## 执行流程

1. 遍历当前修改涉及的所有角色卡叙事文件
2. 按表格逐项扫描，标记所有命中行
3. 逐一改写，确保不引入新的违例
4. 纵向检查同一角色卡下文件间的重复问题
5. 朗读确认通顺性

## 技术备忘

- **头像文件尺寸**: SillyTavern 拒绝过小的头像图片（如 1x1 PNG）。角色卡头像应使用至少 64x64 的 PNG，否则角色卡可能静默创建失败（push 日志显示成功但实际未写入酒馆）。
