# 世界引擎：让 AI 依靠世界观推动交互

## 前言：清单救不了你的世界

大多数人搭世界观的第一步是列清单——几个国家、货币叫什么、修炼分几层、有哪些种族。清单看起来严密宏大，可一进入实际对话就会暴露典型症状：

- NPC 像布景板，只会复述设定里的名词，没有自己的目的；
- 玩家做什么都没有真正的后果，剧情推不动，全靠你在括号里手动写"这时候发生了……"；
- AI 对同一行为的评价飘忽，这次冷漠、下次义愤填膺；
- 换个场景世界观就消失了，退化成"现实世界贴了个魔法标签"。

根因不是设定太少，而是**设定不可执行**。清单只回答"这个世界有什么"，而 AI 生成每一句回复时真正需要知道的是：**谁想要什么、做了会怎样、别人怎么看。**

核心转变只有一句：

> 不要给 AI 一份世界百科，要给 AI 一套裁判规则。

百科是死的，AI 只能背诵；规则是活的，AI 能就玩家的任意行为推演出新的后果。

世界观在交互中承担三个职能，各由一根支柱提供：

| 职能 | 由谁提供 | 缺失后的症状 |
|---|---|---|
| 动机源 | 稀缺与权力循环 | NPC 没有目的，只会接话；一切资源随手可得 |
| 情境生成器 | 链式反应 | 事件随机、前后矛盾，场景没有质感 |
| 裁判系统 | 文明共识 | 道德标准漂移，现代人穿古装演戏 |

三者咬合成闭环后，冲突会从系统内部自己涌现，你不必再手动设计每一场矛盾。

## 支柱一：稀缺与权力循环 —— 给 AI 一台动机发生器

### 原理

世界运转的底层动力是欲望，而欲望之所以能推动故事，是因为稀缺。人人都能随手变出黄金，黄金就不再是货币；灵气对所有人平等开放，修炼等级就失去社会意义。

所以不要写"有什么"，要写：**缺什么、谁控制、代价多高、上升通道多窄、被排斥者如何反抗。**

等级分十层不重要，**每层之间的通道有多窄、由谁把守、卡在瓶颈上的人有多少**才重要。上层为维护垄断立规，底层为打破垄断积怒——对立结构会从资源分配里自己长出来，不需要你额外设计。

### 常见失效

- 只写"灵气复苏，人人可修仙"，不写获取门槛与分配方式。
- 设定了稀缺资源，但主角随手就能买到，稀缺性形同虚设。
- 资源充沛到行动没有成本，AI 只能不断赠予，玩家的选择失去重量。
- 垄断者写成铁板一块，玩家找不到任何撬动点，只能被动挨打。

### 构建方法：资源五联问

每一项关键资源，补全这五格。前四格产生压力，第五格产生**可玩性**。

| 要素 | 要回答的问题 |
|---|---|
| **稀缺物** | 所有人最想要什么？ |
| **控制者** | 谁垄断它？靠什么手段维持垄断？ |
| **代价** | 普通人获取它必须付出什么？（写出具体数字或具体牺牲） |
| **争夺手段** | 被排斥者如何反抗？（黑市、走私、私炼、伪造身份、暴动、投靠外敌） |
| **垄断的裂缝** | 垄断者自身怕什么？内部有几派？什么东西能威胁它？ |

第五格最常被跳过，但没有它，世界就是一堵墙。裂缝是玩家的杠杆：燃灯会内部主战派与商务派不合、精炼配方依赖某种即将枯竭的原料、某位执事的私生子把柄——这些让"对抗垄断"从空谈变成可执行路线。

稀缺物不必是物质。**无形稀缺往往更锋利**：寿命、记忆、姓名、睡眠、真话、一个户籍名额、被神明注视的资格、干净的水。现代/都市题材同样适用——注意力、信用评分、居留权、一次不被记录的机会。

### 写法对比

**清单式（AI 无法使用）：**
> 本世界夜晚有怪物，需要特殊灯油驱散。灯油由燃灯会生产，价格昂贵。

**规则式（AI 可以推演）：**
> **稀缺物**：防魔灯油。一夜标准用量 = 平民三日工钱，约占一户年收入三成。
> **控制者**：燃灯会垄断精炼配方，与各城邦签有排他协议，并掌握巡夜队的调度权。
> **代价**：买不起的人必须日落前归家；夜班工人须签"抵押契"，以五年寿命换长期供油；欠款者转为夜间劳役。
> **争夺手段**：黑市流通劣质油，燃烧不稳定，每月都有整户人在夜里失踪；私自研究配方者被列为"窃火者"，格杀勿论。
> **裂缝**：精炼依赖南境一种正在枯竭的矿脂；会内"配给派"与"扩产派"公开对立；巡夜队薪资被拖欠三月。

### 交互层收益

- **不需要你设计任务**：主角缺钱 → 灯油见底 → 天黑倒计时本身就是压力源。
- **NPC 立场自动生成**：AI 只需知道某个 NPC 处在资源链的哪一环（燃灯会执事 / 夜班苦力 / 黑市贩子 / 欠债者），就能推出他的态度、话术和利益倾向。
- **具体可争夺物**（一条矿脉、一瓶药、一个名额）天然成为剧情引信与关系导火索。

## 支柱二：链式反应 —— 给 AI 一台后果推演器

### 原理

孤立设定是世界观最常见的失效方式：设定了魔法，主角却照样骑马赶路、住普通旅馆、点油灯、靠信使传信，魔法只在战斗时出现。

真实世界牵一发而动全身。一个核心设定像石子入水，波纹必须一圈圈扩散到生产、交通、职业、城市形态、信仰、作息，**最后落到某个具体的人不敢做某件事这件小事上**。

### 构建方法：三层推演链

每引入一个核心设定，至少往下推三层。**推不到第三层不算完成。**

1. **生产力层**：它替代了什么？创造了什么新产业？什么技术因此永远不会被发明？
2. **社会结构层**：谁因此掌权？谁被淘汰？城市形态、阶级、疆域、信息速度如何重组？
3. **个体生活层**：普通人的衣食住行、职业选择、恐惧与梦想变成什么样？成本是多少？

第三层是交互的命脉。AI 只有拿到个体层的细节，才能生成有质感的场景和有具体处境的 NPC。

### 示例一：初级火球术就能烧开一锅水

- **生产力层**：蒸汽机没有发明动机，魔法直接成为主要能源，燃料业与机械工匠阶层消亡。
- **社会结构层**：魔法师行会即能源垄断集团，行会定价等于国策；城市围绕魔法塔布局。
- **个体生活层**：家庭烧水做饭需订购"日供魔契"；付不起的人退回柴火，柴烟味成为贫困标志；孩子的天赋测试决定全家命运。

### 示例二：夜间出现怪物，唯灯光可驱

- **生产力层**：灯油精炼是国家命脉，夜间运输业不存在。
- **社会结构层**：城市围绕巨型灯塔同心圆式向内收缩，越近灯塔越高贵，"外环"即贫民窟；点灯人是最高地位职业之一；夜间不通行导致信息迟滞数日，城邦间形成严重文化隔阂与方言分化；宗教演化为极端光崇拜，熄灯是最重的刑罚。
- **个体生活层**：作息以日落为界，"深夜"一词近乎禁忌；租金按距灯塔距离计算；"夜行者"是亡命之徒的代称；错过宵禁的人要花钱蹲一夜付费灯柱。

### 写进设定的方式：链条 + 玩家限制

每条核心设定后面附一条因果链，末尾标注它对玩家行为的**具体限制**：

```
设定：夜间怪物 + 唯灯光可驱
→ 因此：夜间无法长途移动，跨城信息延迟数日，无法即时求援
→ 因此：城门日落即封，出城须贿赂或走私
→ 玩家限制：日落后离开灯照范围视为高风险行为（无灯油者死亡率约五成，
  巡夜队不救援无契者）；须先解决光源问题
```

### 逆向自检

正向推演容易漏，反向更快暴露问题：随机挑三样日常事物——早饭、房租、约会、葬礼、招工告示——问它们在你的世界里长什么样。如果答案和现实世界一模一样，说明你的核心设定还没有真正接入这个世界。

### 交互层收益

- **AI 生成因果，而不是随机事件**。玩家说"我要开一家旅店"，AI 会自动考虑向谁交税、受哪条垄断限制、哪类客人不能接，而不是回答"你开了一家旅店"。
- **场景自带细节库**。AI 描写街道时会自然写到灯柱、油价、宵禁钟，真实感不需要你逐次提醒。
- **限制即玩法**。买不起、赶不上、被偷走，都是现成的困境。

> 判断标准：当 AI 能自发写出"某个 NPC 因为买不起灯油而不敢深夜出门"时，链式反应才算写通了。

## 支柱三：文明共识 —— 给 AI 一套稳定的裁决基线

### 原理

前两根支柱是外部齿轮，这一根是内在灵魂。每个世界都有集体潜意识：什么天经地义，什么不可原谅，什么值得赴死。

**AI 的默认道德是现代都市价值观。你不覆盖它，它就会用它。** 于是在强者为尊的修仙世界，路人看到强者欺凌弱者会义愤填膺、见义勇为——世界瞬间失真，变成现代人穿古装演戏。

共识还有一个纯交互层的作用：**消除评价漂移**。没有明确基线，AI 对同一行为可能这次冷漠、下次正义，玩家会立刻失去对世界的信任。

### 构建方法：价值过滤器五问

1. **核心美德**：这个世界最崇拜什么？（力量、荣誉、忠诚、血统、洁净、牺牲、财富）
2. **最大禁忌**：什么行为会被全社会唾弃？（逃跑、示弱、欺骗、用禁术、背叛血脉、让灯熄灭）
3. **强弱观**：强者为尊，还是扶弱济困？弱者被怜悯，还是被淘汰？
4. **异类观**：外来者、异族、无信者、无姓者被如何对待？
5. **惩罚形态**：违背共识后，社会用什么方式施压？（拒绝交易、断绝关系、编入耻辱歌谣、剥夺姓名、连坐施助者）

第五问决定共识能否被执行。"他们崇尚荣誉"是形容词，AI 无从下手；写清惩罚形态，AI 才知道该生成什么反应。

### 写法：条件句 + 具体反馈 + 例外

用"在这里，X 等于 Y"的句式，并给出触发与后果：

> **共识**：在兽人氏族，逃跑比死亡更可耻；公开示弱等于永久失去谈判资格。
> **玩家战略性撤退** → 所有兽人 NPC 转为鄙夷；酒馆拒卖酒；雇佣兵拒绝同行；乞丐向他吐口水；旧日盟友当众断交；败逃事迹被编入耻辱歌谣。
> **玩家死战不退** → 即使战败，敌人也会为他收尸并致敬；地位不因输赢改变，只因是否退却而改变。
> **例外**：为救族中幼崽而退可被谅解，但须在下次战斗中自证。

**例外条款很重要**。没有例外的共识是铁律，会把世界写死，玩家只剩服从或毁灭两条路；有了例外，共识变成可以博弈的空间。同理，给共识留出裂缝：改革派、伪信者、私下违规的执法者——他们是玩家的盟友池。

### 进阶：让共识彼此冲突

不要只写一套共识。给不同阵营、城邦、种族各写一套，跨文化接触时冲突会自动爆发：在兽人处的荣誉之举，在商会眼中是愚蠢的资产损失。玩家每一次移动都变成一次价值观重新校准，同一个行为在两地得到相反评价——这是最廉价也最有效的戏剧张力来源。

### 交互层收益

- **反派与配角有据可依**：AI 不再需要你解释反派为何这么做、配角为何牺牲——他们受制于这个世界的价值观。
- **压力驱动选择**：来自全世界的社会压力会逼玩家在"保存实力"与"维护资格"之间做真实取舍，而不是由旁白强行解释"他其实很勇敢"。

## 三根支柱如何咬合

三者不是并列的三段设定，而是一条闭环：

```
稀缺 → 产生动机（角色为什么行动）
  ↓
链式反应 → 产生情境与后果（行动会遇到什么、代价是什么）
  ↓
文明共识 → 产生反馈与裁决（做了之后世界怎么看他）
  ↓
裁决改变他获取资源的能力 → 回到稀缺，且处境已经变化
```

以"灯油世界"跑一遍完整闭环：

主角付不起灯油（**稀缺**）→ 被迫签夜班抵押契，押上五年寿命（**链式反应**：抵押契是灯油垄断催生的制度）→ 他中途弃岗逃离（行为）→ 在把"守夜人"神圣化的光崇拜文明里，弃岗等于渎神（**共识**）→ 被登记为"背光者"，任何店铺不得售油给他（**裁决**）→ 他失去合法获取灯油的渠道，只能投向黑市，而黑市劣质油每月都在杀人（**回到稀缺，风险升级**）。

一次行为，三根支柱各转一格，剧情自动往前走了一整幕。你没有设计任何情节。

再看一个更小的例子：玩家说"我今晚出城"。AI 无需任何补充指令即可推出——需要购油，钱不够（稀缺）→ 城门日落即封，须贿赂或走私（链式）→ 即便成功，守卫与市民都将他视为潜在罪犯，声誉受损（共识）。一句普通行动，长出了成本、障碍与社会后果。

## 工程落地：怎么写进角色卡 / 世界书

原则再好，写法不对 AI 也用不上。

**1. 用规则句，不用描写句。**
凡是无法转化成"如果……则……"的内容都是装饰。
"这是一个残酷压抑的世界" → 不可执行。
"日落后无灯油者外出，死亡率约五成；巡夜队不救援无契者" → 可执行。

**2. 给数值和阈值。**
价格、时限、比例、距离、死亡率，任何可量化的都写出来。AI 需要标尺来判断"贵不贵""来不来得及"，否则会自由发挥并倾向于对玩家宽松。

**3. 按调用场景切分条目，而非按学科切分。**
不要写"经济篇 / 宗教篇 / 地理篇"。要写"夜间外出规则""遭遇燃灯会时的处理""平民物价表"，并挂上触发关键词（灯油、夜晚、燃灯会、宵禁）。组织依据是"AI 什么时候需要它"。

**4. 每条设定后面必须跟一句"所以互动中会发生什么"。**
这是最快的自检。写不出这句话，说明这条设定是死的——删掉或补完。

**5. 分层加载，常驻内容只留裁判规则。**
常驻：稀缺五联问、3–5 条共识与禁忌、当前主要压力。按需触发：历史年表、国家列表、神话谱系、地域细则。它们不参与判定，不值得占用每一轮的注意力。宁可少写十条国家介绍，也不要少写一条禁忌反馈。

**6. 写一条常驻的"当前压力"。**
静态规则只能被动响应，加一条正在恶化的时钟，世界才会主动逼近玩家："南境矿脂将在两个月内枯竭，灯油配给已削减两成，外环开始出现抢油骚乱。"这一句话就让 AI 拥有推进方向。

**7. 写明优先级裁决规则，防止 AI 软化世界。**
例如："当剧情便利与世界规则冲突时，以规则为准。NPC 可以违背共识，但必须承担共识规定的后果。不得为让玩家舒服而降低价格、放宽时限或免除社会评价。"

### 可粘贴的最小骨架

```
【稀缺】稀缺物：__ ｜控制者：__ ｜代价（含数值）：__
        争夺手段：__ ｜垄断裂缝：__
【链条】核心设定：__
        → 生产力：__ → 社会结构：__ → 个体生活（含成本）：__
        → 玩家限制：__
【共识】核心美德：__ ｜最大禁忌：__ ｜强弱观：__ ｜异类观：__
        违背时的具体反馈：__（列出 3 个 NPC 动作）｜例外：__
【当前压力】正在恶化的事：__ ｜留给玩家的时限：__
【裁决】规则与剧情便利冲突时以规则为准；NPC 可违规，但须承担后果。
```

### 最小可运转配置

不需要写完世界才能开始。三样东西就够：

**一项核心稀缺物（五联问填满）+ 一条推到日常细节的改变链 + 三到五条带惩罚形态的共识。**

有这三样，世界就能自己生长；缺的部分可以在互动中沿既有规则补，且补出来的东西天然自洽。

### 压力测试

写完后，抛给 AI 一个你完全没预设的场景——"玩家想开一家旅店""玩家想收养一个孤儿""玩家想请三天假"——看它能否仅凭规则推出合理后果：向谁交税、受哪条垄断限制、哪类客人不能接、社会怎么看。推得出来，引擎成立；推不出来，缺的是链条，不是设定量。

## 常见问题

**设定写得太细，会不会被跳过？**
在传统写作里会——清单是死的，不产生情绪。但交互式角色扮演里这个担忧不成立：**运转中的世界观不是给人阅读的，是被持续调用的。** 玩家不需要读你的设定，他会在每一次被卡住、被评判、被回应时感受到它。当他因为买不起灯油而不敢深夜出门时，他已经相信这个世界存在了。

**设定太多，AI 记不住怎么办？**
所以要区分"裁判规则"与"背景资料"。规则常驻且精简，资料按关键词触发。判断标准很简单：这条内容会不会改变某次判定？不会，就移出常驻。

**现代 / 都市 / 校园题材没有魔法，用得上吗？**
用得上，稀缺物换成无形资源即可：居留权、信用评分、一个保研名额、父母的认可、不被记录的机会。链式反应换成"这项资源的分配制度如何塑造日常"。共识在现实题材里往往更锋利——职场、家族、学校各有一套互相冲突的价值过滤器。

**多人 / 多阵营世界怎么处理？**
稀缺物尽量共用一套（各方争夺同一件东西，才会真正碰撞），共识必须分开写。共用稀缺物 + 分歧共识 = 结构性冲突，几乎不需要额外设计。

## 结语

在交互式 AI 角色扮演中，世界观不是供人参观的布景，而是 AI 的决策依据与仲裁系统。

用**稀缺**制造动机，用**链式反应**生成后果，用**共识**统一反馈。做到这三点，AI 就从"会背设定的聊天机器人"变成"世界运转的推动者"：冲突从规则内部自己涌现，你不再手动设计每一场矛盾；玩家也会真切感到自己身处一个活着的世界，因为他的每一个选择都被这个世界评判、限制和回应。

不要搭背景板，要造一台裁判机。世界一旦开始自己产生后果，你就从"手动编剧"变成了"规则制定者"。
